# Texas Web Design

Austin web studio site: websites, local SEO, AI SEO, AI tools and lead gen for local small businesses.

Design: paper-cutout sticker system (Barlow Condensed / Barlow / Permanent Marker, all OFL; licenses in assets/fonts).
Static HTML, CSS and a little JS. No build step.

Claims on the page come from the owner: Examcat 500+ users, Corgi Cafe 5,000+ users in under 7 days,
four Austin-area businesses appearing in AI answers. S.W.A.T. is a concept demo. No public fixed pricing.
The Search/AI/phone mockups are labelled illustrations with placeholder names.
